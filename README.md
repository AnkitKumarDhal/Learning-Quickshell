# Quickshell Config — Hyprland Bar & Popups

A modern, Material You-inspired Hyprland bar configuration built with Quickshell (QML). Features a sleek top bar with workspace switching, system monitoring, media controls, notifications, and slide-in popups for volume, network, Bluetooth, and system stats.

## ✨ Features

### Bar Modules
- **Left**: Arch logo, workspaces with active window name
- **Center**: Clock/date, media player with spinning disc art, idle inhibitor toggle
- **Right**: System monitor (CPU/RAM), network status, volume, battery, system tray, notification button

### Popups
- 📬 **Notification Panel** — Scrollable list with timestamps, clear all, empty state
- 🔊 **Volume Popup** — Output/input sliders, mute buttons, device selector
- 🌐 **Network Popup** — WiFi scanner, password prompt, Bluetooth devices, hotspot placeholder
- 💻 **System Popup** — Speedometers (CPU/RAM/GPU), disk bars, live network graph, temperature
- 🔔 **Toast Notifications** — Slide from right, stack upward, auto-expire

### Smart Behavior
- **Focus Mode** — Auto-collapse on fullscreen apps (`SUPER+Z` for manual override)
- **Material You Theme** — Colors generated by `matugen` from wallpaper
- **Native Tray Menus** — Right-click system tray icons for platform-native context menus
- **Quick Actions** — Right-click pills for mute/play-pause, scroll for volume adjust

## 🚀 Requirements

- **Hyprland** (with Lua config support)
- **Quickshell** (use `quickshell-git` from AUR — stable 0.3.0 lacks `Quickshell.Networking`)
- **matugen** (for Material You color generation)
- **pipewire** (audio + Bluetooth)
- **systemd** (for idle inhibition via `systemd-inhibit`)
- **AMD GPU** (for GPU usage stats via `/sys/class/drm/card*/device/gpu_busy_percent`)

### Optional Dependencies
- `awww` + `swww` (for wallpaper picker popup — Phase 2)
- `bluez` (Bluetooth support)
- NetworkManager or iwd (WiFi scanning)

## 🛠️ Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/AnkitKumarDhal/Learning_Quickshell.git ~/.config/quickshell
   cd ~/.config/quickshell
   ```

2. **Install quickshell-git** (Arch Linux):
   ```bash
   yay -S quickshell-git
   ```

3. **Generate initial colors** (requires a wallpaper):
   ```bash
   matugen --config ~/.config/quickshell/src/theme/matugen_config.json /path/to/wallpaper.jpg
   ```

4. **Start Quickshell**:
   ```bash
   qs &
   ```

5. **Reload after changes**:
   ```bash
   pkill -SIGTERM qs
   qs &
   ```

## ⌨️ Keybindings

| Key | Action |
|-----|--------|
| `SUPER+Z` | Toggle focus mode (manual override) |
| `LEFT_CLICK` on pill | Open corresponding popup |
| `RIGHT_CLICK` on volume | Mute/unmute |
| `RIGHT_CLICK` on media | Play/pause |
| `SCROLL` on volume | Adjust volume |
| `ESC` | Close any open popup |

## 🎨 Theming

Colors are generated by `matugen` into `src/theme/Colors.json`. The QML engine watches this file and reloads automatically.

### Color Properties (Mixed snake_case)
All colors in `Colors.qml` use mixed snake_case naming:
- `background`, `on_Background`
- `surface`, `on_Surface`, `surfaceContainer`, `surfaceContainerHigh`
- `primary`, `on_Primary`, `primaryContainer`
- `secondary`, `tertiary`, `error`, `outline`, `shadow`

### Design Tokens (`Theme.qml`)
```qml
borderWidth: 3
barHeight: 36
pillHeight: 30
pillRadius: 15
popupRadius: 14
animDuration: 250
hoverOpacity: 0.15
```

## ⚠️ Known Gotchas

- `//@ pragma UseQApplication` must be in `shell.qml` ONLY — never in component files
- Popup cards must be **siblings** of `PopupSlide`, not children
- `Pipewire.sinks` / `.sources` don't exist — filter `Pipewire.nodes.values` instead
- `WaylandIdleInhibitor` is not available — use `systemd-inhibit` process
- `Quickshell.Networking` requires **quickshell-git**, not stable 0.3.0
- `WifiDevice` has NO `activeNetwork` property — filter `.networks.values` for `connected === true`
- `WifiNetwork.signalStrength` is 0.0–1.0, NOT a percentage
- `Bluetooth.connectedDevices` can be null at startup — use `?.values ?? []`
- Colors must be `color` type (not `string`) for `.r/.g/.b` access
- Tray submenus are permanently broken (DBusMenuHandle/QsMenuHandle mismatch) — don't touch
