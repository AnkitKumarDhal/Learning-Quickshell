## Design Spec

### Bar
- Single `PanelWindow`, full width, `implicitHeight: 36`
- Three `RowLayout`s anchored left/center/right inside one `Item`
- `barMargin: 8`, `barSpacing: 10`
- Focus mode: collapses to `borderWidth: 3` strip on fullscreen
- `focusMode = _isFullscreen AND NOT _manualOverride`
- Manual override via `SUPER+Z` (`GlobalShortcut`, appid: "quickshell", name: "focusModeToggle")
- Override resets when fullscreen exits

### Pills
- `height: 30`, `radius: 15`, `color: Colors.background`
- Width: `contentWidth + 32` (Theme.pillPadding)
- Hover bg: `Colors.primary` at 15% opacity
- Hover expand: `+10px` animated 150ms OutCubic
- No tooltips, no text hover effect

### Popups
- Left-click opens popup (toggles Popups.*Open bool)
- Right-click = quick action (mute, play/pause)
- Scroll = quick adjustment (volume)
- All popups are `PanelWindow` with `PopupSlide` sibling (NOT parent) to the card
- Card is anchored `top/right` inside the PanelWindow, sibling of PopupSlide
- `PopupDismiss` handles click-outside + Escape + workspace change via `Popups.closeAll()`
- `visible: slide.windowVisible` on PanelWindow — NOT bound to open bool directly

### System Tray
- Uses `//@ pragma UseQApplication` in shell.qml
- Right-click calls `modelData.display(root.window, pos.x, pos.y)` for native platform menus
- `mapToItem(null, mouse.x, mouse.y)` used to get correct screen coordinates
- `Tray` has `property var window` set from `TopBar` as `Tray { window: root }`
- `TrayContextMenu.qml` exists but is NOT used — native menus only

## Key Implementation Details

### Colors.qml — CRITICAL NAMING
All color properties use **mixed snake_case** — this is NOT camelCase. Exact names:
```
background          on_Background       surface             on_Surface
surfaceVariant      on_SurfaceVariant   surfaceContainer    surfaceContainerHigh
surfaceContainerHighest                 primary             on_Primary
primaryContainer    on_PrimaryContainer secondary           on_Secondary
secondaryContainer  on_SecondaryContainer tertiary          on_Tertiary
tertiaryContainer   on_TertiaryContainer  error             on_Error
errorContainer      on_ErrorContainer   outline             outlineVariant   shadow
```
All are `readonly property color` (NOT string) — critical for `.r/.g/.b` and `Qt.rgba()` to work.
FileView watches `src/theme/Colors.json` for live reloading.

### Fonts.qml
- `font`: "Space Mono"
- `fontM`: "JetBrains Mono"

### PillBase.qml
- `default property alias contentData: innerLayout.data` — children flow directly in
- `mouseEnabled: false` disables input for tray/custom-input pills
- `hoverEnabled: false` disables highlight without disabling input
- Uses `MouseArea` not `HoverHandler`
- Signals: `clicked(mouse)`, `rightClicked(mouse)`, `scrolled(wheel)`
- Has `hoverExpand: bool` property for the +10px hover width animation

### PopupSlide.qml
- `windowVisible` output — bind `PanelWindow.visible` to this
- `open: bool` input property (NOT `openState`)
- `edge: "top"` default
- `slideCloseTimer` keeps window alive during slide-out
- `onCloseRequested` signal for two-way binding

### Popup window pattern (ALL popups follow this exactly):
```qml
PanelWindow {
    id: root
    property var screen
    color: "transparent"
    exclusionMode: ExclusionMode.Ignore
    anchors { top: true; right: true }
    implicitWidth: 380
    implicitHeight: root.screen ? root.screen.height : 800
    WlrLayershell.layer: WlrLayer.Overlay
    visible: slide.windowVisible

    PopupSlide {
        id: slide
        anchors.fill: parent
        edge: "top"
        open: Popups.xyzOpen
        onCloseRequested: Popups.xyzOpen = false
    }

    Rectangle {   // ← card is SIBLING of PopupSlide, NOT inside it
        anchors {
            top: parent.top; right: parent.right
            topMargin: Theme.barHeight + 8; rightMargin: Theme.barMargin
        }
        // ... content
    }
}
```

### TabBar.qml
- Props: `model: [{key, icon, label}]`, `currentPage: string`, `orientation: "horizontal"|"vertical"`
- Signal: `onPageChanged(key)`
- Has scroll-to-cycle tabs built in
- Horizontal: icon + label row with bottom divider
- Vertical: icon-only column

### Workspaces.qml
- Dispatch: `Hyprland.dispatch("hl.dsp.focus({ workspace = " + wsId + " })")`

### IdleInhibitor.qml
- Process: `["systemd-inhibit", "--what=idle", ...]`
- `WaylandIdleInhibitor` NOT used — not available

### NotificationService.qml
- `_arrivalMap` persists timestamps after toast expiry
- `formatTimestamp()` reads `_tick` to auto-update every 30s
- `activeToasts` is ID list only

### ToastItem.qml
- Separate file prevents QML engine jitter
- Animates via `y` + `opacity` — NO height animation
- Slides in from right, stacks upward via `anchors.bottomMargin` Behavior

### VolumePopup.qml
- Device list: `Pipewire.nodes.values.filter(n => n.audio !== null && !n.isStream && n.isSink)`
- `Pipewire.sinks` / `Pipewire.sources` do NOT exist — use nodes filter
- `PwObjectTracker` placed inside `PanelWindow` scope

### NetworkGraph.qml
- `slideOffset` + `NumberAnimation` for smooth 60fps scrolling
- `ctx.save()` / `ctx.clip()` / `ctx.restore()` prevents graph bleeding

### SystemStats.qml (src/services/system/)
- GPU: AMD only via `/sys/class/drm/card*/device/gpu_busy_percent`
- Disk: `df -B1`, skips /boot /boot/efi /snap
- Network: auto-detects by highest traffic, skips lo/docker/br-
- Temperature: highest from `/sys/class/thermal/thermal_zone*/temp`
- Poll: 1s main timer, disk every 10 ticks

### NetworkService.qml (NEW — src/services/)
- `import Quickshell.Networking` + `import Quickshell.Bluetooth`
- Requires **quickshell-git** — `Quickshell.Networking` not in stable 0.3.0
- `wifiDevice`: first device where `type === DeviceType.Wifi`, or null
- `activeNetwork`: first network in `wifiDevice.networks.values` where `connected === true`
- `networks`: sorted array — connected first, then by descending `signalStrength`
- `scannerActive`: set to `true` when popup opens — drives `wifiDevice.scannerEnabled`
- `btAdapter`: `Bluetooth.defaultAdapter`
- `btDevices`: `Bluetooth.connectedDevices?.values ?? []`
- `WifiNetwork.signalStrength` is 0.0–1.0 (NOT a percentage)
- There is NO `activeNetwork` property on `WifiDevice` — find active by filtering `.connected`
- `Pipewire.sinks` equivalent: there is no shorthand — always filter `.networks.values`

### Network.qml pill (NEW — src/modules/Right/)
- Visible only if `hasWifi || btAdapter !== null || hasEthernet`
- Shows ethernet icon `󰈀` if no WiFi but ethernet active (via SystemStats.activeInterface)
- Label collapses (hidden) when disconnected or wifi disabled
- Left-click toggles popup, opens to tab 0 (WiFi) or 1 (BT) depending on what's present
- Right-click opens popup to tab 2 (Hotspot placeholder)
- Uses `onClicked`/`onRightClicked` signals from PillBase — NO extra MouseArea

### NetworkPopup.qml (NEW — src/popups/)
- Follows standard popup window pattern above
- Has `WlrLayershell.keyboardFocus: WlrKeyboardFocus.OnDemand` for TextField input
- Uses `Binding` object to sync `NetworkService.scannerActive = Popups.networkOpen`
- 3 tabs: Wi-Fi (0), Bluetooth (1), Hotspot (2 — placeholder)
- WiFi tab: toggle switch + scrollable network list via `NetworkRow` delegates
- BT tab: toggle switch + connected device list with battery % if available
- Hotspot tab: "coming soon" placeholder

### NetworkRow.qml (NEW — src/popups/)
- Separate file for jitter-free Repeater delegates
- `required property var network` — receives `WifiNetwork` object
- Full-row `MouseArea` (with hover) handles connect/disconnect on click
- Lock icon toggles `_showPsk` manually; also set automatically via `onConnectionFailed(NoSecrets)`
- Password field uses `TextField` from `QtQuick.Controls` (NOT bare `TextInput`)
- `connectWithPsk(text)` called on Enter or confirm button
- Connected state shown as chip (not a button)

## Known Gotchas

- `//@ pragma UseQApplication` in shell.qml ONLY
- Card must be SIBLING of `PopupSlide`, NOT inside it — card anchors to PanelWindow directly
- `required property var modelData` + `required property int index` is correct delegate pattern
- `Pipewire.sinks` / `.sources` don't exist — use nodes filter
- `WaylandIdleInhibitor` not in this build — use systemd-inhibit
- Colors use mixed snake_case: `on_Surface`, `on_Primary`, `on_Background` etc — NOT camelCase
- Colors must be `color` type not `string` — needed for `.r/.g/.b` access
- `Quickshell.Networking` requires **quickshell-git**, not stable 0.3.0
- `WifiDevice` has NO `activeNetwork` property — filter `.networks.values` for `connected === true`
- `WifiNetwork.signalStrength` is 0.0–1.0, not a percentage
- `Bluetooth.connectedDevices` can be null at startup — always use `?.values ?? []`
- `NetworkService.wifiHardwareEnabled` can be undefined at startup — use `?? true` fallback
- `TextField` from `QtQuick.Controls` needed for `placeholderText` — bare `TextInput` doesn't have it
- TrayContextMenu submenus permanently broken (DBusMenuHandle/QsMenuHandle type mismatch) — don't touch
- `pkill -SIGTERM qs` for clean exit

## Architecture Decisions

| Decision | Choice | Reason |
|---|---|---|
| Bar layout | Single flat bar, three RowLayouts | Notch upgrade planned for Phase 3 |
| ShellState | Kept with width tracking | Future notch upgrade uses it |
| Popup trigger | Click-open (left) | More intentional than hover |
| Right-click | Quick action | Mute, play/pause |
| Scroll | Quick adjust | Volume |
| Tray menus | Native display() | QsMenuOpener/DBusMenuHandle type mismatch unfixable |
| Idle inhibitor | systemd-inhibit | WaylandIdleInhibitor not in build |
| GPU | AMD only via gpu_busy_percent | Intel has no clean usage % API |
| Fonts | Two fonts | Space Mono text, JetBrains Mono icons |
| Colors type | `color` not `string` | Enables .r/.g/.b and Qt.rgba() |
| Colors naming | mixed snake_case | Matches matugen output keys |
| TabBar | Both H + V | Chosen per popup |
| focusMode | Auto + SUPER+Z | Override resets on exit |
| Tray input | mouseEnabled: false + z:10 on delegates | Avoids PillBase MouseArea blocking |
| Popup card | Sibling of PopupSlide in PanelWindow | Correct animation without nesting issues |
| Network backend | Quickshell.Networking (native) | Reactive, no polling, fits project style |
| Quickshell version | quickshell-git | Required for Quickshell.Networking |
| BT disconnect | `modelData.connected = false` | Direct property write, no method needed |
| Network scanner | `scannerActive` via Binding | Only scans while popup is visible |
